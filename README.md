# Starfall Exodus

Tarayıcıda oynanan, OGame tarzı mobil uzay imparatorluğu oyunu. Tek dosya (`index.html`), kurulum gerektirmez.

## GitHub Pages ile yayınlama
1. Bu klasördeki dosyaları yeni bir repoya yükle.
2. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `root` → Save.
3. 1–2 dakika sonra `https://KULLANICI.github.io/REPO/` adresinden aç.

## Telefona uygulama gibi ekleme
- iPhone: Safari → Paylaş → Ana Ekrana Ekle
- Android: Chrome → ⋮ → Ana ekrana ekle / Uygulamayı yükle

Kayıt tarayıcının yerel hafızasında tutulur (localStorage).
